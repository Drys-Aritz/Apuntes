HTML Y MAQUETACION

Estructura de una página

Las etiquetas semánticas describen cada parte; CSS las organiza.

<header> Cabecera
<nav> Menú
<article>

Contenido principal

Un artículo puede entenderse por sí solo, como una noticia o una entrada.

<aside>

Información secundaria, como una nota o una barra lateral.

<footer> Pie de página

Idea clave: HTML crea las partes; Flexbox o Grid las colocan. En CSS Grid, grid-template-areas asigna un nombre a cada zona.

El selector elige qué elemento HTML recibe los estilos.

  • .aviso selecciona elementos con clase aviso.
  • #menu selecciona id="menu".

Organizar elementos en filas y columnas

Dentro de las llaves se escribe una propiedad y su valor: color: blue;.

Columnas

grid-template-columns: 1fr 1fr; crea dos columnas iguales.

Separación
