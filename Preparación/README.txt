APUNTES DAW (Modelo Teorico) — HTML, CSS, JavaScript, PHP y SQL
================================================

CONTENIDO
- html/01-html.html: estructura HTML, textos, enlaces, listas, tablas y formularios.
- css/02-css.css: selectores, caja, tipografía, formularios, tablas, flex, grid, responsive.
- js/03-js.js: variables, operadores, condicionales, bucles, funciones, arrays, DOM, eventos, JSON y fetch.
- php/04-php-basico.php: sintaxis, tipos, condiciones, bucles, arrays, funciones, formularios y JSON.
- php/05-pdo-mysql.php: conexión PDO y ejemplos CRUD.
- sql/06-sql-basico.sql: base de datos, tabla, INSERT, SELECT, UPDATE, DELETE, agregaciones y JOIN.
- Apuntes_DAW_Completos.pdf: manual unificado para imprimir o consultar.

CÓMO USARLO
1. Abre cada archivo en VS Code para consultar o editar el código.
2. El HTML enlaza con el CSS y el JS usando rutas relativas; para que las rutas coincidan,
   mantén las carpetas con esta estructura.
3. El HTML de ejemplo carga el JS con defer. El JS incluye un formulario de demostración.
4. El archivo PHP 04 es un catálogo de ejemplos, no una página que deba ejecutarse entera
   tal cual: contiene demostraciones de salida y lectura de datos.
5. El archivo PHP 05 es un conjunto de ejemplos CRUD independientes. No ejecutes INSERT,
   UPDATE y DELETE en una base real sin revisar antes los datos y el objetivo.
6. Para ejecutar PHP y MySQL, necesitas un servidor local como XAMPP y una base de datos
   configurada. Abrir el archivo PHP directamente desde el explorador no ejecuta PHP.
7. Los ejemplos de credenciales son únicamente para un entorno local de práctica.

NOTA
Son apuntes de estudio. En una aplicación real añade autenticación/autorización cuando sea
necesario, validación de servidor, gestión segura de secretos, protección frente a CSRF cuando
corresponda y registro de errores sin exponer información sensible.
