# Guía de JavaScript para preparar el examen

Material de estudio organizado por temas, con ejemplos comentados, variantes y ejercicios de práctica.

## Cómo usar esta carpeta

1. Abre `index.html` en el navegador para consultar la guía como una página web.
2. Abre los archivos `.md` con VS Code, Obsidian, Typora o cualquier editor de texto.
3. Los ejemplos `.js` y `.html` están separados por tema para que puedas probarlos.
4. Empieza por los ejemplos y después intenta los ejercicios sin mirar las pistas.

## Estructura

- `00-inicio/`: mapa de contenidos y chuleta rápida.
- `01-arrays/`: arrays, objetos, recorridos, búsquedas y transformaciones.
- `02-clases-objetos/`: clases, constructores, métodos y propiedades.
- `03-dom-eventos/`: selección de elementos, eventos y creación de HTML.
- `04-formularios/`: lectura de campos, validación y expresiones regulares.
- `05-web-storage/`: localStorage, sesiones y preferencias.
- `06-ejercicios/`: simulacro adicional y retos mixtos.
- `index.html`: página de inicio para consultar la guía en el navegador.

## Nota

Los ejemplos están pensados para practicar JavaScript de nivel inicial. En los archivos HTML se utiliza `defer` para cargar el JavaScript cuando el documento ya está disponible.
