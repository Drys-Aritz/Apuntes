Antes de empezar

Cómo estudiar con esta guía

No memorices líneas sin entenderlas. Aprende a reconocer qué herramienta pide cada enunciado.

1. Identifica los datos¿Tienes un array, una clase, un formulario o elementos HTML?
2. Identifica la acción¿Te piden buscar, mostrar, validar, guardar o eliminar?
3. Elige la estructuraFunción, recorrido, condición, evento o clase.
4. Prueba dos casosUno que cumpla la condición y otro que no.
Consejo: intenta primero los ejercicios del final sin consultar los ejemplos. Después vuelve aquí para comprobar qué método o estructura te faltaba.
Bloque 1

Arrays: métodos y alternativas

Un array almacena varios elementos. En los ejercicios suelen ser objetos con propiedades.

const productos = [
  { nombre: "Teclado", precio: 35, stock: 4 },
  { nombre: "Taza", precio: 8, stock: 12 },
  { nombre: "Ratón", precio: 18, stock: 0 }
];

Recorrer: forEach()

Ejecuta una acción para cada elemento. No devuelve un array nuevo.

productos.forEach(function(producto) {
  console.log(producto.nombre);
});

Filtrar varios: filter()

Devuelve un array nuevo con todos los elementos que cumplen la condición.

function productosBaratos() {
  return productos.filter(function(producto) {
    return producto.precio < 20;
  });
}

Buscar el primero: find()

Devuelve el primer elemento que coincide o undefined si no encuentra ninguno.

const raton = productos.find(function(producto) {
  return producto.nombre === "Ratón";
});

Transformar: map()

Crea un array nuevo con el resultado de transformar cada elemento.

const nombres = productos.map(function(producto) {
  return producto.nombre;
});

Acumular: reduce()

Sirve para sumar precios, calcular medias, contar o acumular resultados.

const total = productos.reduce(function(suma, producto) {
  return suma + producto.precio;
}, 0);

Comprobar: some() y every()

// ¿Algún producto está agotado?
const hayAgotados = productos.some(function(producto) {
  return producto.stock === 0;
});

// ¿Todos tienen precio positivo?
const preciosCorrectos = productos.every(function(producto) {
  return producto.precio > 0;
});

Ordenar: sort()

// De menor a mayor precio. Modifica el array original.
productos.sort(function(a, b) {
  return a.precio - b.precio;
});

// De mayor a menor:
// productos.sort((a, b) => b.precio - a.precio);
MétodoDevuelveUso típico
forEachNada útil (undefined)Recorrer y ejecutar acciones
filterArrayTodos los que cumplen
findElemento o undefinedEl primero que coincide
mapArrayTransformar elementos
reduceAcumuladoSumar o calcular
some / everytrue o falseAlguno / todos cumplen
sortArray ordenadoOrdenar; modifica el original
Pista de examen: «devuelve todos» suele indicar filter; «el primero» indica find; «un array con los nombres» indica map; «la suma» indica reduce.
Bloque 2

Clases y objetos

Una clase es una plantilla. Con new creas objetos concretos a partir de ella.

Patrón básico

class Libro {
  constructor(titulo, autor, paginas) {
    this.titulo = titulo;
    this.autor = autor;
    this.paginas = paginas;
  }

  descripcion() {
    return `${this.titulo}, de ${this.autor}, tiene ${this.paginas} páginas.`;
  }
}

const libro1 = new Libro("Libro A", "Autora A", 120);
console.log(libro1.descripcion());

Variante A · Método que devuelve true o false

class Alumno {
  constructor(nombre, nota) {
    this.nombre = nombre;
    this.nota = nota;
  }

  estaAprobado() {
    return this.nota >= 5;
  }
}

const alumno = new Alumno("Ane", 8);
console.log(alumno.estaAprobado()); // true

Variante B · Método que modifica una propiedad

class Cuenta {
  constructor(titular, saldo) {
    this.titular = titular;
    this.saldo = saldo;
  }

  ingresar(cantidad) {
    if (cantidad > 0) {
      this.saldo += cantidad;
    }
  }

  retirar(cantidad) {
    if (cantidad > 0 && cantidad <= this.saldo) {
      this.saldo -= cantidad;
    }
  }
}

Variante C · Método que calcula

class Rectangulo {
  constructor(ancho, alto) {
    this.ancho = ancho;
    this.alto = alto;
  }

  calcularArea() {
    return this.ancho * this.alto;
  }

  esCuadrado() {
    return this.ancho === this.alto;
  }
}
Recuerda: clase = plantilla; objeto = instancia; propiedad = dato; método = función de la clase; this = el objeto actual.
Bloque 3

DOM y eventos

El DOM permite seleccionar y modificar elementos de la página desde JavaScript.

Patrón básico: seleccionar y escuchar un clic

const boton = document.getElementById("accion");
const resultado = document.getElementById("resultado");

boton.addEventListener("click", function() {
  resultado.textContent = "Has pulsado el botón";
});

Variante A · Cambiar una clase CSS

const tarjeta = document.getElementById("tarjeta");

tarjeta.addEventListener("click", function() {
  tarjeta.classList.toggle("seleccionada");
});

Variante B · Mostrar u ocultar

boton.addEventListener("click", function() {
  if (panel.style.display === "none") {
    panel.style.display = "block";
  } else {
    panel.style.display = "none";
  }
});

Variante C · Eliminar un elemento

botonEliminar.addEventListener("click", function() {
  elemento.remove();
});

Variante D · Reaccionar mientras se escribe

campo.addEventListener("input", function() {
  resultado.textContent = campo.value;
});

Variante E · Reaccionar al cambiar un select

selector.addEventListener("change", function() {
  salida.textContent = selector.value;
});

Crear una lista desde un array

const tareas = ["Estudiar", "Leer", "Practicar"];
const lista = document.getElementById("lista");

tareas.forEach(function(tarea) {
  const li = document.createElement("li");
  li.textContent = tarea;
  lista.append(li);
});
InstrucciónPara qué sirve
getElementById()Selecciona un elemento por su id.
querySelectorAll()Selecciona todos los elementos que coinciden con un selector CSS.
createElement()Crea un elemento HTML.
append()Añade un elemento al final de otro.
remove()Elimina un elemento.
classList.toggle()Añade o quita una clase CSS.
Importante: si el script está en el <head>, utiliza <script src="archivo.js" defer></script>. Si creas un elemento dentro de un forEach, coloca sus eventos dentro del mismo recorrido.
Bloque 4

Formularios y validación

Lee los valores, comprueba las condiciones y muestra errores o confirmación.

Plantilla general

const formulario = document.getElementById("miFormulario");

formulario.addEventListener("submit", function(event) {
  event.preventDefault();

  const campo = document.getElementById("campo");
  const mensaje = document.getElementById("mensaje");
  const valor = campo.value.trim();

  mensaje.textContent = "";

  if (valor === "") {
    mensaje.textContent = "El campo es obligatorio";
    mensaje.style.color = "red";
  } else {
    mensaje.textContent = "Correcto";
    mensaje.style.color = "green";
  }
});

Variante A · Comprobar longitud

const nombreValido = nombre.length >= 3 && nombre.length <= 30;

Variante B · Comprobar edad entre dos valores

const edad = Number(campoEdad.value);
const edadValida =
  campoEdad.value !== "" && edad >= 18 && edad <= 100;

Variante C · Correo electrónico

const regexCorreo = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
const correoValido = regexCorreo.test(correo);

Variante D · Contraseña de al menos 8 caracteres

const passwordValida = password.length >= 8;

Variante E · Dos campos deben coincidir

const password = document.getElementById("password").value;
const repetir = document.getElementById("repetir").value;

const coinciden = password === repetir;

Mostrar varios errores

mensaje.textContent = "";
mensaje.style.whiteSpace = "pre-line";

if (!nombreValido) {
  mensaje.textContent += "Nombre incorrecto.\n";
}
if (!correoValido) {
  mensaje.textContent += "Correo incorrecto.\n";
}
if (!passwordValida) {
  mensaje.textContent += "Contraseña incorrecta.\n";
}

Regex que conviene reconocer

ExpresiónSignificado
/^\d{4}$/Exactamente cuatro cifras.
/^\d{5}$/Exactamente cinco cifras.
/^[a-zA-Z]{3,20}$/De 3 a 20 letras inglesas.
/^[^\s@]+@[^\s@]+\.[^\s@]+$/Formato básico de correo.

Símbolos: ^ inicio · $ final · \d dígito · \s espacio · {3,50} entre 3 y 50 · + una o más.

Ojo: Number("") produce 0. Por eso, cuando validas números, comprueba también que el campo no esté vacío.
Bloque 5

Web Storage

Permite guardar datos en el navegador para recuperarlos más adelante.

AlmacenamientoDuración
localStoragePermanece hasta que se borre.
sessionStorageSe mantiene durante la sesión de esa pestaña.

Guardar, recuperar y eliminar

// Guardar un dato
localStorage.setItem("idioma", "es");

// Recuperarlo
const idioma = localStorage.getItem("idioma");

// Eliminar esa clave
localStorage.removeItem("idioma");

Guardar un número

localStorage.setItem("puntos", 25);

// Los datos recuperados son texto: convertimos a número.
const puntos = Number(localStorage.getItem("puntos"));

Guardar objetos y arrays con JSON

const usuario = { nombre: "Ane", edad: 21 };

// Convertir el objeto a texto JSON para guardarlo.
localStorage.setItem("usuario", JSON.stringify(usuario));

// Recuperar el texto y convertirlo otra vez en objeto.
const texto = localStorage.getItem("usuario");

if (texto !== null) {
  const usuarioRecuperado = JSON.parse(texto);
  console.log(usuarioRecuperado.nombre);
}

Añadir un elemento a una lista guardada

function guardarFavorito(nuevoFavorito) {
  const texto = localStorage.getItem("favoritos");
  const favoritos = texto === null ? [] : JSON.parse(texto);

  favoritos.push(nuevoFavorito);

  localStorage.setItem("favoritos", JSON.stringify(favoritos));
}
Precaución: no guardes contraseñas ni datos sensibles en localStorage. El JavaScript de la página puede acceder a esos datos.

Practica

Simulacro de examen: 10 ejercicios

Resuélvelos sin mirar las pistas. Están planteados como enunciados, para que practiques identificar la estructura.

  1. Arrays: con un array de libros, devuelve los que cuesten menos de 20 €, busca uno por título, crea un array de títulos y calcula el total de páginas.
  2. Clases: crea una clase CuentaBancaria con titular y saldo. Añade métodos para ingresar dinero y consultar el saldo.
  3. DOM: crea un botón que cambie el texto de un párrafo y lo ponga de color azul.
  4. Formulario: pide una edad, comprueba que no esté vacía y que sea un número entre 1 y 120.
  5. Web Storage: guarda una ciudad favorita, recupérala al entrar y añade un botón para borrarla.
  6. Arrays + DOM: muestra tareas como elementos li y añade un botón para eliminar cada tarea.
  7. Clases + arrays: crea tres objetos Producto y muestra los que tengan un precio superior a 10 €.
  8. Regex: valida un código postal de exactamente cinco cifras.
  9. Storage + JSON: guarda un objeto con nombre y edad, recupéralo y muestra el nombre.
  10. DOM + input: crea un buscador que muestre en un párrafo lo que se escribe en tiempo real.

Pistas, sin solución completa

  • Varios resultados: filter. Primer resultado: find.
  • Una lista de propiedades: map. Una suma: reduce.
  • Modificar la página al pulsar: evento click.
  • Reaccionar al escribir: evento input.
  • Guardar un objeto: JSON.stringify; recuperarlo: JSON.parse.
Evita perder puntos

Errores frecuentes en el examen

  • Escribir Constructor en vez de constructor.
  • Olvidar this.propiedad = parametro dentro del constructor.
  • Olvidar el return dentro de filter o reduce.
  • Confundir return (devuelve) con console.log (muestra por consola).
  • Usar = en vez de === para comparar.
  • Colocar un evento fuera del bloque donde se crea el elemento.
  • Olvidar event.preventDefault() en el envío de un formulario.
  • Olvidar limpiar los mensajes anteriores de validación.
  • Creer que localStorage.getItem() devuelve null cuando la clave no existe, no una cadena vacía.
  • Olvidar que los datos de Web Storage se recuperan como texto.
  • No usar defer cuando el script se carga desde el head.
Último consejo: en cada ejercicio, escribe primero el esqueleto. Por ejemplo, selecciona elementos, crea el evento y después completa la condición o el recorrido. Es más fácil detectar errores así.
