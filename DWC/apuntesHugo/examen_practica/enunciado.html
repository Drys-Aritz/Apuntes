Examen Práctico — Versión C

Empresa: Tienda de Zapatillas Deportivas

Valor total: 10 puntos · Tipo: procedimental

Instrucciones: Cada ejercicio es independiente. Completa los archivos JavaScript indicados en cada apartado. Una vez terminado, comprime la carpeta y súbela a Moodle.

Ejercicio 1 — Arrays de objetos (2 puntos)

En el archivo Ej1_arrays/zapatillas.js dispones de un array inicial con varios objetos literales de zapatillas deportivas, cada uno con: nombre, marca, talla, precio, categoria.

  1. Crea una función mayusculas() que muestre por consola todos los nombres de las zapatillas en mayúsculas.
  2. Crea una función zapatillasPorCategoria(categoria) que devuelva un nuevo array solo con las zapatillas de la categoría indicada.
  3. Crea una función buscarPorNombre(texto) que devuelva todas las zapatillas cuyo nombre contenga el texto indicado (sin distinguir mayúsculas/minúsculas). Por ejemplo, debería encontrar "Air Max 90" escribiendo "max".
  4. Crea una función mediaPrecios() que devuelva un valor con la media de los precios de todas las zapatillas.
Nota: Las funciones 2, 3 y 4 deben return un valor o un array, no mostrarlo por consola.

Ejercicio 2 — Objetos y clases (1,5 puntos)

Crea una clase Zapatilla con las propiedades: nombre, marca, talla, precio, categoria.

  1. Define un constructor que inicialice estas propiedades.
  2. Implementa un método mostrar() que devuelva una cadena con este formato literal:
"Air Max 90 (Nike), talla 42, precio 120 €, categoría Running"
  1. Crea dos objetos de la clase Zapatilla, guárdalos en un array y recórrelo mostrando el resultado de mostrar() por consola.

Ejercicio 3 — Eventos y DOM (2,5 puntos)

En el archivo Ej3_dom/index.html hay un listado <ul id="listaZapatillas"> vacío y un botón con id="btnMostrar".

  1. Asocia al botón un evento que, al pulsarlo, recorra el array de zapatillas y muestre cada nombre como un <li> dentro de la lista.
  2. Se valorará positivamente que utilices las funciones del DOM (createElement, appendChild, textContent) y no uses innerHTML o similares.
  3. Añade un efecto: si el usuario pasa el ratón por encima de un nombre de zapatilla, este se pondrá en negrita; al salir, volverá al estilo normal.

Ejercicio 4 — Validación de formularios (2,0 puntos)

En el archivo Ej4_formulario/formulario.html existe un formulario con los campos: nombre, marca, precio, categoria y un botón de tipo submit con id="validar".

Implementa en Ej4_formulario/validacion.js la validación con las siguientes condiciones:

  1. nombre y marca: deben tener entre 3 y 50 caracteres alfabéticos. Usa una expresión regular que lo compruebe.
  2. precio: debe ser un número entero comprendido entre 0 y 9999.
  3. categoria: no puede estar vacía.

Si algún campo no cumple los requisitos, debes mostrar los errores (todos juntos en un único mensaje, o cada uno de manera independiente). Si todo es correcto, el formulario no se enviará, pero se mostrará el mensaje "Zapatilla validada correctamente" en el <div id="mensaje">.

Nota: Puedes modificar el formulario para añadir restricciones en las etiquetas HTML si lo necesitas, pero no se valorará validación realizada únicamente con HTML5.

Ejercicio 5 — Web Storage (2,0 puntos)

En Ej5_webstorage/usuario.html hay un formulario con un botón "Login".

  1. Al enviar el formulario con el botón "Login", guarda el nombre del usuario en localStorage.
  2. Si ya existe un usuario guardado, en lugar del formulario se mostrará el mensaje: "Bienvenido de nuevo, <usuario>" y un botón "Cerrar sesión".
  3. Al pulsar "Cerrar sesión", se eliminará el usuario de localStorage y se volverá a mostrar el formulario.
